QR Generator from the iPhone Share Sheet

iOS doesn't support PWA Web Share Targets. You can still add QR Generator to the home screen using Safari's Add to Home Screen; to receive shared URLs or text, create a simple Apple Shortcut:

  1. Open the Shortcuts app, tap +, and name the shortcut QR Generator.
  2. Open the shortcut's details and enable Show in Share Sheet. Set accepted input types to URLs and Text.
  3. Add URL Encode and set its input to Shortcut Input (Encode, not Decode).
  4. Add a Text action. Insert the following prefix, immediately followed by the blue variable for URL Encoded output of the previous action:
https://tools.fishese.cc/qr/#type=text&data=
  1. Add URL, taking its input from the Text action, then add Open URLs with the URL result.
  2. Save. From Safari or another app, choose Share → QR Generator.

A shared link is encoded as text, but QR scanners still recognize the underlying link. Text and URLs never become HTTP query parameters; the generator clears the fragment after reading it.

Clipboard alternative

To make a second shortcut that runs from your home screen, replace Shortcut Input in step 3 with a Get Clipboard action. Leave the other actions the same.

Note: A preinstalled, signed Shortcut requires creation and sharing from Apple's Shortcuts app; this page provides the exact local steps instead of claiming to offer an unverified iCloud install link.
