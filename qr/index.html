Your QR code

Enter something on the left to generate a QR code.

Private by design. QR codes are generated entirely in this browser. QR content is generated and handled on your device; the tool doesn't upload it or save it. Bookmarklets and PWA shares briefly use URL fragments (after #), which aren't sent with HTTP requests, and the page clears the fragment after reading it. Shared data is intercepted locally by the installed service worker. Avoid sharing secrets via bookmarklets or share sheets. After installation, QR Generator can work offline.

Install & share

Install QR Generator for offline use. On supported Android browsers, the installed app can receive links or text directly from the system Share menu.

On Android, use your browser's menu → Install app or Add to Home screen if no install button appears. Install it before looking for QR Generator in the Share menu.

On iPhone, use Safari → Share → Add to Home Screen. For receiving links and text from the iOS Share Sheet, set up an Apple Shortcut.

Quick QR bookmarklets

Drag one of these links to your browser's bookmarks bar. On another webpage, click that bookmark to open a ready-made QR code. If dragging doesn't work, use Copy code and paste it into a bookmark's URL field.

🔗 Page → QR Generate a QR for the current webpage address.
📋 Clipboard → QR Use copied text; asks you to paste if the browser blocks clipboard access.
✨ Choose → QR Pick current URL, selected webpage text, or clipboard contents.

Browser security settings can restrict bookmarklets or automatic clipboard reading. Pasting manually is always an option.
